# BetterDivvy

A tiny macOS menu bar app for resizing windows on a grid, in the spirit of Divvy.

- **⌥\`** opens the grid over the focused window; press it again to cycle 4×4 → 8×8 → 2×2.
- Drag across cells and release to snap the window there. **Esc** cancels.
- Needs Accessibility permission (System Settings → Privacy & Security → Accessibility).

Build and run: `./build.sh && open build/BetterDivvy.app`
